# Aishwarya V V — Personal Portfolio

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

## What's included
- Responsive navigation for desktop and mobile
- Dark / light theme toggle (the selected theme is remembered in the browser)
- Scroll progress indicator and back-to-top button
- Scroll reveal effects and active navigation state
- Project filters (All work, Academic, Personal)
- Certificate search
- One-click email copy with confirmation message
- Resume and certificate links

## Run locally
1. Extract the ZIP file.
2. Open the `AishwaryaPortfolio` folder.
3. Double-click `index.html` to open it in a browser.

Keep `index.html`, `style.css`, `script.js`, the `images` folder, the `certificates` folder, and the resume PDF together in the same project folder so all links continue to work.
